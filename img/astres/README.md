Copies réduites (1024 × 512) des cartes de l'Observatoire (dépôt `observatoire`, `textures/README.md` pour le détail des sources).

Les exoplanètes n'ont pas de carte : leur surface est calculée (`themes/poste-pilotage/worlds.js`) d'après les données mesurées, et le scanner l'indique (« vue d'artiste d'après les données »).
